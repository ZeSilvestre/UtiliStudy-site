Política de Privacidade – UtiliStudy

O UtiliStudy respeita a privacidade dos seus usuários e se compromete a proteger seus dados.

Coleta de informações

O aplicativo pode coletar informações básicas necessárias para o funcionamento, como dados inseridos pelo próprio usuário para organização de estudos.

Login com Google

O UtiliStudy utiliza login com Google no aplicativo desktop para autenticação, backup no Google Drive e vinculação da licença. O ID Token é validado pela API UtiliStudy para gerar sessão segura. Não há login web neste site.

Licença e pagamentos

O UtiliStudy funciona por plano de uso. A assinatura é contratada exclusivamente no aplicativo desktop via Mercado Pago. Processamos e-mail, identificador do dispositivo e histórico de pagamentos para controle de licença. Dados de dispositivo (nome, último login) são exibidos ao usuário para segurança da conta.

Armazenamento de dados

Os dados do usuário são armazenados localmente no dispositivo e, quando autorizado, podem ser enviados para o Google Drive do próprio usuário.

Compartilhamento de dados

O UtiliStudy não compartilha dados pessoais com terceiros.

Segurança

Adotamos medidas para proteger as informações armazenadas, mas o usuário também é responsável pela segurança de sua conta.

Alterações

Esta política pode ser atualizada para melhorias no aplicativo.
